## Executive Overview

This repository is a premium **Data Analyst / Business Intelligence** portfolio project. It demonstrates how raw sales records can become a polished executive reporting experience with KPI design, SQL analysis, dashboard presentation, and business recommendations.

The goal is not just to show code. The goal is to show **business thinking**: asking the right questions, choosing useful metrics, explaining what changed, and turning analysis into decisions.

---

| Area | What it shows |
|---|---|

| **SQL Analysis** | Regional, category, channel, product, and segment queries |
| **Dashboard Design** | Clean KPI cards, comparison bars, and insight sections |
| **Data Storytelling** | Clear recommendations based on business questions |

---

## Business Questions Answered

| Question | Why it matters |
|---|---|
| Which regions generate the most revenue? | Helps leadership prioritize regional investment |
| Which categories drive the strongest sales? | Shows where product focus should go |
| Which customer segments are most valuable? | Supports better sales targeting |
| Which channels perform best? | Guides direct, partner, and online strategy |
| What trends deserve executive attention? | Turns raw data into business action |

---

## KPI Snapshot

| KPI | Purpose |
|---|---|
| **Total Revenue** | Measures overall sales performance |
| **Gross Profit** | Shows revenue quality after cost |
| **Average Order Value** | Identifies customer value per sale |
| **Revenue by Region** | Compares market performance |
| **Revenue by Category** | Highlights product/category strength |
| **Channel Performance** | Compares direct, online, and partner sales |

## Dashboard Preview

This repo includes a lightweight visual dashboard preview built with **HTML, CSS, and JavaScript**.

```bash
cd dashboard
python -m http.server 5173
```

Then open:

```text
http://localhost:5173
```

You can also open `dashboard/index.html` directly in your browser.
