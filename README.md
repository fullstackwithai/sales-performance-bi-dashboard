# Sales Performance BI Dashboard

> Executive-style business intelligence dashboard for analyzing sales revenue, regional performance, product categories, customer segments, and monthly growth trends.

Built by **Arsim Shefkiu** under **FullStackWithAI** — full-stack, AI-assisted, and data-driven web solutions.

---

## Overview

This repository is a premium **Data Analyst / Business Intelligence** portfolio project. It shows how raw sales data can be transformed into executive insights, KPI summaries, trend views, and decision-ready recommendations.

The project is structured like a real business analytics case study: source data, SQL analysis, dashboard preview, and an executive summary.

---

## Business Questions

- Which regions generate the most revenue?
- Which product categories are growing or declining?
- Which customer segments contribute the most value?
- What monthly trends should leadership pay attention to?
- Which channels and regions deserve more investment?

---

## Key Metrics

- Total revenue
- Monthly revenue growth
- Average order value
- Revenue by region
- Revenue by product category
- Customer segment performance
- Sales channel performance
- Top-performing products

## Dashboard Preview

Open the dashboard locally:

```bash
cd dashboard
python -m http.server 5173
```

Then visit:

```text
http://localhost:5173
```

You can also open `dashboard/index.html` directly in your browser.
